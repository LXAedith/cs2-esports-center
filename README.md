# Espor Merkezi

Bütün espor branşlarını tek ekranda toplayan, sade ve hızlı bir maç takip sitesi.

**[lxaedith.github.io/espor-merkezi](https://lxaedith.github.io/espor-merkezi/)**

- **Canlı:** Şu an oynanan maçlar ve anlık skorlar. Maça tıklayınca resmi yayın açılır.
- **Yaklaşan:** Önümüzdeki haftanın fikstürü, güne göre sıralı.
- **Sonuçlar:** Son bir haftada oynanan maçların skorları.
- **Ligler:** Aktif turnuvalar ve güncel puan durumu.
- **Takımlar:** Logolarıyla birlikte; tıklayınca takımın Liquipedia sayfası açılır.
